# Dream Home Designes — Admin Dashboard

Standalone Admin Website for managing products and blogs for **Dream Home Designes**.

## Features
- **Shared Firebase**: Connects to the same Firestore database (`products` and `blogs` collections) as the customer-facing website.
- **Product Management**: Add, update, badge, categorize, and delete affiliate products.
- **Blog Management**: Add, update, and manage room transformation blog posts.
- **Secure Access**: Simple credentials-based authentication.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```
   Opens on [http://localhost:3001](http://localhost:3001).
